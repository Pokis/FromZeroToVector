Act 1 • The "Zero-Math" Mental Model

You Already Understand Vector Spaces: The 2D Taste Map

An embedding is just a list of numbers (float[]) representing coordinates along meaning axes.

2 Human-Named Axes: float[2]

  • Axis 0 (X): Sweetness (0 to 10)
  • Axis 1 (Y): Crunchiness (0 to 10)
  • 🍎 Apple = [ 7.5, 8.0 ]
  • 🍐 Crispy Pear = [ 7.0, 7.2 ] → Lands right next to Apple!
  • 🥔 Potato Chip = [ 1.2, 9.2 ]
  • 🍰 Chocolate Cake = [ 9.4, 1.5 ]

Scaling Up to AI Models: float[384..3072]

An AI embedding model is a deterministic function:

f(input) -> float[384]

Instead of 2 human axes, it learns 384 to 3,072 abstract axes ("is it a billing issue?", "is it urgent?", "is it C# code?") where geometric proximity = semantic similarity.

Act 1 • Geometric Intuition

Cosine Similarity in 1 Sentence: Measure the Angle, Not the Ruler

Draw two arrows from the origin (0, 0). If they point in the same direction, their meaning is aligned—regardless of document length.

cos(0°) = +1.00

Identical Direction
Arrows point the exact same way. High semantic similarity (typically > 0.75 in production).

cos(90°) = 0.00

Orthogonal (90° Apart)
Completely unrelated concepts (e.g., "Postgres deadlock" vs "Golden retriever puppy").

Senior Perf Tip ⚡

Because models normalize vectors to unit length (||v|| = 1.0), Cosine Similarity == Dot Product: just SUM(a[i] * b[i]) in SIMD!

Act 1 • Under the Hood (Zero Jargon)

How Are Embeddings Generated? The 4-Stage Pipeline

An embedding model isn't a dictionary lookup—it's a 4-step geometric compressor trained via Contrastive Learning.

1. Chunk & Tokenize

Text: Sub-words ["un", "believ", "able"] → [348, 9102, 481]
Image: 16×16 pixel patches
Audio: Spectrogram patches

2. Contextualize

Transformer Self-Attention updates every token based on surrounding words: "apple" moves toward "iPhone" or "banana" based on context.

3. Pool (Squash)

Mean Pooling averages the 500 token vectors into a single fixed-size float[384] coordinate array representing the whole passage.

4. L2 Normalize

Scales the vector so its length equals 1.0, placing every item on the surface of a unit hypersphere.

Act 3 • 0:22 – 0:38 • Live C# Coding

Semantic Search in ~25 Lines of Modern C# (.NET 10)

using System.Numerics.Tensors;
using ElBruno.LocalEmbeddings;
using Microsoft.Extensions.AI;

// 1. Local ONNX model (100% offline, swaps with OpenAI/Ollama via DI)
IEmbeddingGenerator<string, Embedding<float>> embedder =
    await LocalEmbeddingGenerator.CreateAsync();

string[] tickets = [
    "Payment gateway returns 502 error at checkout",
    "How do I reset my two-factor authentication?",
    "App crashes when uploading a profile picture",
    "Invoice PDF shows the wrong VAT rate"
];

// 2. Turn strings into float[384] coordinates
var ticketVectors = await embedder.GenerateAsync(tickets);

// 3. Hardware SIMD-accelerated Cosine Similarity!
var queryVector = await embedder.GenerateVectorAsync(query);
var best = tickets.Zip(ticketVectors)
    .Select(x => (Ticket: x.First,
        Score: TensorPrimitives.CosineSimilarity(
            queryVector.Span, x.Second.Vector.Span)))
    .OrderByDescending(x => x.Score).First();

Two Game-Changing .NET Primitives

  • IEmbeddingGenerator<string, Embedding<float>> (Microsoft.Extensions.AI): The standard abstraction across .NET. Swap local ONNX for Azure OpenAI, Ollama, or Gemini by changing 1 line of DI registration.
  • TensorPrimitives.CosineSimilarity (System.Numerics.Tensors): Built-in AVX2/AVX-512/NEON SIMD hardware acceleration over ReadOnlySpan<float>.

Act 4 • 0:38 – 0:50 • Architectural Patterns

Five High-Leverage Patterns Beyond Chatbots & RAG

Use float[] vectors as deterministic, sub-millisecond building blocks in regular microservices—zero LLM generation required.

1. Zero-Shot Routing & Classification (< 1ms)

Embed 5 queue anchor descriptions at startup. Route incoming webhooks via TensorPrimitives.Dot in microseconds with zero model training.

2. Semantic Caching & Deduplication

Before creating a duplicate Jira ticket or calling a $0.03 LLM endpoint, check if CosineSimilarity > 0.90 exists in cache.

3. Anomaly & Log Drift Detection

Compute the mean centroid vector of normal logs. Alert when a log line lands outside a distance threshold—catching novel failures regex misses.

4. Stateless Recommendations ("More Like This")

Represent a user's live taste profile by averaging the float[] vectors of the last 5 items they clicked, then query nearest neighbors.

Act 4 • Pattern #5 • Multimodal Shared Spaces

How Text, Images, and Audio Share the Exact Same Space

Modern multimodal models (CLIP, SigLIP, Gemini Embedding 2, Qwen3-VL) train Text, Vision, and Audio encoders side-by-side using Contrastive Learning.

One Vector Space to Search Them All

  • 📝 Text: "golden retriever puppy" → [ +0.21, -0.44, +0.81 ... ]
  • 🖼️ Image (ViT Patches): IMG_0042.jpg → [ +0.19, -0.42, +0.79 ... ]
  • 🔊 Audio (Spectrogram): barking.wav → [ +0.18, -0.40, +0.77 ... ]

Your database doesn't care where the float[] came from—one query searches screenshots, PDFs, audio calls, and docs simultaneously!

Engineering Subtlety: "The Modality Gap"

Even in shared spaces, image vectors and text vectors hover in slightly separated sub-clouds (like oil and water).

Pro Tip: Normalize per-modality centroids or use smaller-gap models (SigLIP / Gemini Embedding 2) when mixing text and image candidates in a single top-K cutoff.

Act 4 • Model Architecture Selection

Why Embedding Models Differ: The 5 Engineering Axes

Dimension / Axis What Varies Between Models Why It Matters in Production
1. Specialization (Symmetric vs Asymmetric) General similarity vs Q&A retrieval vs Code models (e.g., voyage-code-3) Short queries don't look like 500-word docs! Asymmetric models use prefixes like "query: " vs "passage: ".
2. Context Window Legacy models cap at 512 tokens; modern models handle 8K–32K+ A 512-token model silently truncates pages 2–10 of your PDF!
3. Vector Dimensions 384 (MiniLM) up to 3,072+ (OpenAI large / Gemini) 10M vectors @ 3,072 float32 = 122 GB RAM vs 384 dims = 15 GB RAM.
4. Language & Domain English-only vs 100+ languages (BGE-M3 / Qwen3) vs Legal/Medical English-only models map non-English text almost randomly.
5. Local Weights vs API ONNX / Ollama (0$/tok, on-prem privacy) vs Cloud APIs Local ONNX runs in <2ms on CPU with zero data leaving your VPC.
Act 5 • 0:50 – 1:00 • Where Embeddings Lie

Gotcha #1: Embeddings Are Blind to Negation & Exact IDs

Dense vectors capture general topic, not boolean logic or exact alphanumeric identifiers.

❌ The Failure Mode

  • "How to ENABLE MFA" vs "How to DISABLE MFA" → 94% Cosine Similarity!
  • "HTTP Error 503" vs "HTTP Error 504" → 91% Cosine Similarity!
  • Searching for SKU "AX-9920-B" returns random parts in the same category.

✔ The Fix: Hybrid Search + RRF

Always pair Dense Vector Search with BM25 Keyword Search and merge rankings via Reciprocal Rank Fusion (RRF):

RRF_Score(doc) = 1 / (60 + DenseRank)
               + 1 / (60 + BM25Rank)
Act 5 • Production Cost & Memory Optimization

Gotcha #2: The Storage & RAM Cliff (And How to Shrink Vectors 32x)

Storing 10M vectors at 3,072 float32 dimensions requires ~122.9 GB of RAM. Two modern tricks solve this:

🪆 1. Matryoshka Representation Learning (MRL)

Modern models train coarse semantic concepts into the first dimensions and fine details into the tail.

You can slice float[3072] → float[256] and re-normalize with TensorPrimitives.Norm, cutting memory 12x while keeping ~95%+ recall!

🗜️ 2. Scalar (int8) & Binary (1-bit) Quantization

  • float32 → int8: 4x RAM reduction, <1% recall loss.
  • float32 → 1-bit Binary (ulong[]): 32x RAM reduction! Search uses hardware CPU BitOperations.PopCount(a ^ b), then rescores the top 50 in float32.
Act 5 • Chunking & Model Lifecycle

Gotchas #3 & #4: Context-Destroying Chunking & Model Lock-In

Gotcha #3: Naive Chunking Orphans Context

Splitting every 500 characters produces chunks like:
"It returns a 502 error when payload exceeds 4MB." (What is "It"?!)

Fix (Contextual Chunking): Prepend document & section headers to every chunk before embedding:
"[Doc: Stripe Gateway > Checkout Limits] It returns..."

Gotcha #4: Vector Spaces Are Incompatible!

Even if Model A and Model B both output float[768], comparing a Model B query against Model A database rows produces random noise (~0.00 similarity).

3 Defensive Rules:
1. Store model_id & model_version on every row.
2. Use Blue/Green Vector Columns (embedding_v1, embedding_v2) to backfill before flipping traffic.
3. Consider compatible model families (Voyage 4 / Cohere) for asymmetric query/index tiers.

Act 5 • Wrap-Up & Q&A Cheat Sheet

The Production Vector Cheat Sheet (Take-Home Matrix)

Where Should I Store My Vectors?

  • < 10K vectors: In-memory ReadOnlyMemory<float> + TensorPrimitives.CosineSimilarity (<1ms, zero infra!).
  • 10K – 20M vectors: PostgreSQL + pgvector (HNSW index). Keep relational joins, ACID, and vectors in one DB.
  • 50M – 1B+ vectors: Dedicated Vector DB (Qdrant, Milvus, Weaviate) with distributed sharding & quantization.
